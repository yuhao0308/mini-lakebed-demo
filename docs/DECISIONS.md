# Architecture Decision Records

This file tracks implementation decisions that are not explicitly covered by the specification documents, or where specs are ambiguous.

## Format

Each decision should follow this format:

```
### [DECISION-XXX] Title

**Date:** YYYY-MM-DD
**Status:** Proposed | Accepted | Deprecated | Superseded
**Context:** What is the issue or question?
**Decision:** What was decided?
**Rationale:** Why was this decision made?
**Spec Reference:** Which spec doc (if any) this relates to, or "N/A - Gap in specs"
**Consequences:** What are the implications?
```
